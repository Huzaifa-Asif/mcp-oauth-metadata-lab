# Contributing

By contributing, you agree that your contribution is licensed under MIT. Open an issue before a large change. Keep the project zero-dependency unless a documented security and maintenance case justifies otherwise.

1. Use synthetic fixtures only.
2. Run `npm run check` on Node 20 or newer.
3. Add tests for success, failure, size bounds, redaction, and deterministic behavior.
4. Update README, threat model, research notes, and changelog when behavior changes.

Pull requests should explain the user problem, protocol source, limitations, security/privacy impact, and verification evidence.
