# Privacy

The application runs locally in the browser or CLI. It has no telemetry, analytics, cookies, accounts, remote APIs, or persistence. It does not fetch submitted URLs. Browser input remains in the page until reload; CLI input is read from the path supplied by the user. Reports contain finding metadata, not submitted field values.

Do not provide credentials, tokens, private keys, personal data, or production logs. Secret-like fields are flagged but detection is intentionally incomplete. GitHub Pages, GitHub, or a local network administrator may process ordinary access metadata when those services are used; consult their policies. To delete local data, close/reload the page and remove files you created.
